# Precision Oncology for Breast Cancer Diagnosis
Master’s Thesis Research Repository

## Overview

This directory contains the scripts for flux estimations.

---

## `/CountCarbons.mlx`

This script is a function necessary for the calculation of Carbon Uptake.

## `/Models_names_saved.mlx`

This script reads all models and save them into a txt. document.


## `/Pareto_multiobjective_1226_models.mlx`

This script creats the pareto surface maximazing biomass and ATP while minimizing Carbon Uptake and Enzyme abundance.

## `/Norms_1_2_fluxes-nurvo.mlx`

This script calculates FBA, pFBA, WL1, L2, WL2 and secundary fluxes.

## `/prepareModel.mlx`

This cript is a function also necessary for securing the biomass flux, before calculating the fluxes.
