# Precision Oncology for Breast Cancer Diagnosis
Master’s Thesis Research Repository

## Overview

This directory contains the datasets and resources used for the construction of genome-scale metabolic models (GEMs), metabolic flux analysis, and clinical data integration for precision oncology research in breast cancer.

---

## `/Metabolic fluxes calculation MATLAB`

This directory contains scprits for the metabolic fluxes estimation such as:

- FBA, pFBA, WL1, L2, WL2 and pareto multiobjective.

## `/GEMS Code for Construction`

This directory contains the MATLAB and Python scripts used for the creation of the 1226 metabolic models: 

- Code for Gems construction
- Exploratory analisys of GEMs

## `/Clustering and data analysis in Python`

This directory contains the python scripts for unsupervised learning models trained using:
- Clinical data
- Metabolic data
- Correlations between clusters using ARI

Each directory contains versions of the algorithms using PCA and UMAP technichs. The folder archived contains old versions of code and images.
