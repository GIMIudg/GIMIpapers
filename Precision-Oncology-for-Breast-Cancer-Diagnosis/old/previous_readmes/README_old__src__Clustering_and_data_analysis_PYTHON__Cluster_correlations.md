# Cluster Correlations Analysis

This directory contains scripts, notebooks, and results for the clustering and correlation analysis of the Precision Oncology for Breast Cancer Diagnosis project, specifically focusing on differentiating "Core" and "Divergent" patient groups.

## 📂 Directory Structure

### Files
- **`Clustering_Correlation_Analysis.ipynb`**
  The main R/Jupyter notebook that implements the final statistical pipeline. It loads metabolic and clinical data, performs non-parametric statistical analysis (Wilcoxon, FDR correction, Cliff's delta), and generates the final figures (boxplots, heatmaps, forest plots, Kaplan-Meier curves) and statistical summary tables for the study.
  
- **`correlation_main.py`**
  A Python backend script that handles clustering metrics (like Adjusted Rand Index), data parsing, and the generation of 3D plots and other visualizations. It contains strict styling configurations (colors, DPI, Arial font) to comply with PLOS ONE publication standards.

### Folders
- **`Figures_PLOS_v6/`**
  The designated output folder for all high-resolution figures (TIFF/PDF formats) and CSV statistical summaries (`Metabolic_Statistics_CoreVsDivergent.csv`, `Significance_Summary_ByGroup.csv`) generated by the analysis notebooks. These outputs are formatted to meet PLOS ONE publication guidelines (e.g., 300 DPI, LZW compression).

- **`results/`**
  Contains the processed input lists defining the patient groups (e.g., `divergent_patients_study_pyn.csv`, `core_patients_correlation_ParetoAndNorms.csv`), as well as various clustering metrics and 3D visual outputs produced by the Python and R scripts.

- **`archived/`**
  Stores older iterations, tests, and previous results from earlier stages of the analysis. It is kept for historical record and reproducibility purposes.

## 🚀 Workflow Summary
1. The analysis requires metabolic data (from PCA models) and clinical data.
2. Patient identifiers are matched and split into "Core" and "Divergent" groups using the lists in `results/`.
3. The R notebook computes statistical differences across multiple metabolic and clinical variables.
4. Results are exported automatically to `Figures_PLOS_v6/` for final publication review.
